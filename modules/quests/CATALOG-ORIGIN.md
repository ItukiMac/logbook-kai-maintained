# Quest catalog provenance

670 source records imported from data, draft and outdated. Only game_id and
name are projected. Each record retains its exact source URL and separate source
edition. Draft records are provisional; outdated records are historical. None is
proof of availability, current edition or completion. All start UNKNOWN.
No claim of exhaustive coverage of the live game is made. Newly observed and
manually entered identities are retained independently. Matching game observations
to these historical/provisional source editions requires explicit evidence.
