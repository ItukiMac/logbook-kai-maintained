# logbook-kai2 品質改善計画・実施記録

更新日: 2026-10-31。機能移行の基準はPR #84。品質改善はPR #85で追跡します。

## 確定方針

製品名はlogbook-kai2。本体coreと8機能JAR（ships / equipment / quests / records / charts / calculators / bridge / sharing）を同じリポジトリで管理します。過去版との関係を最低限にし、移行は再取得不能な履歴・手動情報の明示的コピーに限定します。継承コードと依存物のライセンス表示は保持します。利用者向け情報はdocs/user、開発者向け情報はdocs/developerに分離します。

機能移行は利用者判断で完了した範囲を前提とします。本計画は製品整理とLinux並行試験準備であり、過去の任務定義の全ルールを再検証済みとするものではありません。

## 運用上の境界

旧環境のファイル・設定・記録を変更しません。キットの起動スクリプトは展開場所の絶対パスを使うため、準備後にキットを移動しないでください。

新しい拡張は旧8891への送信を維持し、kai2を独立キューで処理します。32件/64MiB、1件5秒で打ち切り、失敗・超過を表示します。再送や拡張再起動後のキュー復元は行いません。欠落した区間を完全一致の比較に使わず、再読込後に比較を再開します。

対象はLinux。Windows/macOS実機の認定、実環境へのインストール、ゲームへの操作、公開リリースはこの自動検証の完了に含めません。
