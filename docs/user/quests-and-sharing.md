# 任務管理と情報出力

任務管理表で観測状態・完了履歴を確認できます。報酬受領の成功を完了として記録し、未接続中の完了などは理由付きの手動補正で管理します。ゲーム観測と手動補正は区別され、後続観測との不一致を確認できます。

未観測の任務は不明として扱います。初期台帳は出典付きですが、現在の全任務を網羅したと保証するものではありません。過去の完了をゲームから必ず再取得できるとは限らないため、完了履歴は保存対象です。

「情報の共有・出力」から全情報または区分別にJSON/CSVをプレビューし、コピー・保存します。対象には艦娘、装備、基地、任務管理、資材、各種記録などが含まれます。出力内容は共有前に確認してください。
