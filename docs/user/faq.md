# FAQ

## 艦娘画像が出ない

画像はゲーム画面で取得したものを保存します。新規環境では再取得が必要です。ブラウザ連携を開始してゲームを再読込し、対象の画面を表示してください。ゲームの画像は配布キットに含めません。

## 表が空、情報が古い

接続状態、取得時点、絞り込み条件を確認します。並行拡張で失敗・欠落がある場合はゲームを再読込して現在情報を揃えます。完了済み任務の過去履歴は再読込だけでは復元できない場合があります。

## 過去の完了を補正したい

任務管理表で対象行を選び、日時・状態・理由を指定して手動更新します。ゲーム内の状態は変更しません。手動記録と後続のゲーム観測は別々に保持されます。

## 旧logbookと同時起動できない

別フォルダーだけでなくポートも分けます。[Linux並行試験手順](linux-parallel-test.md)を参照してください。

## 更新後に戻したい

管理起動では更新世代を残します。アプリ終了後にmanagerのrollbackを使用します。ユーザーの記録は巻き戻されないので、データの退避とアプリの世代切替を区別してください。
