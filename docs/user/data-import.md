# データの引き継ぎ

logbook-kai2は新規環境を基本とし、旧版との双方向同期は行いません。

| 対象 | 扱い |
| --- | --- |
| 艦娘・装備・資材などの現在値 | 再接続で取得 |
| マスター・再取得可能な画像・キャッシュ | 再取得・再生成 |
| 接続設定・画面位置・列幅 | 新規設定 |
| 戦闘・遠征・開発・資材推移の過去記録 | 保持・取り込み対象 |
| 任務完了履歴・手動補正・独自メモ/定義 | 保持・取り込み対象 |

元データを残し、コピーから一方向に取り込みます。再取得できるか不明な情報は削除しません。全旧形式の自動取り込みが完成したことを意味するものではなく、対象形式・件数・検証結果を確認して取り込みます。

## コピーによる取り込み

旧アプリを終了して採ったコピーを入力にします。書き込み中の元フォルダーは使用しません。

```sh
python3 scripts/import_retained_data.py --source /path/to/old-copy \
  --out /path/to/new-retained-copy \
  --include 資材ログ.csv --include config/quest-ledger
```

選択したファイルだけが同じ相対配置でコピーされます。設定・画像・キャッシュ・プラグイン・シンボリックリンクは対象外です。存在しない入力や既存の出力先は拒否します。import-report.jsonの件数とSHA-256を確認します。IMPORT_INCOMPLETEがある出力は不完全なので使用しません。元ファイルは保持されます。

対応する任意選択の対象は、直下CSV、battlelog/battle/reports、config/quest-ledger、到達履歴、およびラベル・保存編成・独自任務条件・経験値記録などの明示された設定ファイルです。全旧形式を自動変換するツールではありません。形式を読めるかは別コピーで起動して確認します。

新規のkai2 runtimeへ配置する際も、同名ファイルがあれば上書き・結合せず比較します。特に任務台帳のイベント列をファイル単位で混ぜないでください。新しい実機試験では旧履歴を入れず開始しても問題ありません。
