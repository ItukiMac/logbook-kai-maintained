# 港到達条件の編集UI（2026-10-27）

基点: a094771d73ce420f2bd2ddf237e0c69cf2005067。PR48（移行/保守）・PR49（残件台帳）は未統合であり、このブランチはそれらを前提としない。

## 実装

達成条件の1-6行に「港到達」チェックを追加。既存のarrival:trueを読み戻して表示し、回数の編集、新規追加、戦闘条件への明示切替を可能にする。選択中はS/A/B・マス入力を無効にし、到達条件に戦闘のrank/cell/boss:trueを出力しない。未保存の戦闘入力は画面内に保持し、切替を戻せば復元する。到達回数は正の整数を必須とし、空欄/ゼロ/負数/小数/文字列/整数上限超過は保存前に拒否する。

海域欄の空白変更や他海域の追加で、既存行の入力・到達モードを消さない。選択中の1-6を海域欄から消す場合は明示解除を要求し、矛盾中は保存を中止する。別任務への切替では全行と矛盾状態をリセットする。

既存のQuestEditorDocument差分保存・QuestDocumentStoreの変更前退避と変更検出をそのまま利用する。無編集では元バイト・コメントを維持。画面で表せないrank:C等の条件を失う変換は黙って行わず保存拒否する。到達を使わない新規通常条件へarrival:falseを追加せず、不要なパック能力宣言を増やさない。
