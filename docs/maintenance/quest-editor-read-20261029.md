# 任務編集の選択肢・入力フォーム読取境界 — 2026-10-29

基点: PR69統合2aff776dc0112a36c65797dee7192a4a4d77f03e。
QuestEditorDataV1は選択肢・入力既定値・艦種グループ・保存済みフォーム値を不変コピーで提供する。
通常候補は従来のカテゴリ2/8/9/10かつ組込定義のない観測任務、カスタムは10001〜10005。
既存QuestListV1と定義世代leaseを利用する。残存カスタムキャッシュは通常候補へ混在させない。
画面は可変AppQuestを保持せず、元の観測が後で変わっても既に選択したID/タイトル/分類は変わらない。
元キャッシュ、観測日時、保存期限、受諾状態の変更は行わない。

保存済み入力は既存QuestDocumentValidationを用いる。重複/後続JSON、到達・艦隊番号・退避の検査を維持する。
編集用の従来投影と同様、未知フィールドは表示型へ取り込まないが、元のraw bytes/JSONは保持する。
Formは完全な保存文書ではない。未表示フィールドの保持は既存差分マージが担当する。
フィルター・再帰編成・到達/戦闘行・入力語彙は不変コピーで、欠損値や期限を勝手に補わない。
Store/DocumentService/Validation/EditorDocumentの内容、FXML、設定キー、保存形式、ゲーム条件/期限計算は無変更。
