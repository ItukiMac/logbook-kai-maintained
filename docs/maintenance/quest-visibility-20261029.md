# 任務表示操作の非破壊コマンド化 — 2026-10-29

基点: b87d0139d3c25db63ab29035df4762d80b55a92e（PR65統合済み）。
本変更は任務の表示操作だけを分離する。定義編集・永続削除・任務UI全体のJAR化ではない。

## 明示した仕様変更
旧「除去」は観測キャッシュを削除し、カスタム任務ではJSONを直接削除していた。
新「非表示」はこのJVMの起動中だけIDを非表示にする。旧remove/removeAllハンドラー名はFXML互換で保持するが、
意味は明示的に非破壊表示操作へ変更する。定義・元キャッシュ・受諾履歴・JSON・設定を消さない。
カスタム任務枠は解放されない。永続削除と誤解しないよう、確認画面と復帰バナーに説明する。
非表示中に同じIDのゲーム進捗が変わっても、この起動中の非表示設定は維持する。
再表示または新しいJVM起動で全て見える状態へ戻る。設定ファイルや新保存形式は追加しない。

## 構造
QuestVisibilityV1のState/Plan/Resultは防御コピーされた不変値。
QuestVisibilityServiceが表示状態だけを所有し、prepareで対象IDと表示世代を固定する。
確認がキャンセルされたら無変更。確認中に他コマンドが入った場合は全体をCONFLICTとして拒否し、勝手に再試行しない。
applyは同サービスのlock内で世代と対象を反映する。表示コマンド同士の整合性であり、ゲームwriter全体の同期ではない。
confirmed引数は呼出し契約であり、本人認証や外部プラグイン権限の安全境界ではない。
型上限超過・不正ID・重複対象は副作用前に検査。操作のリストにファイルパスを持たない。

QuestPaneのremove/removeAllはQuestVisibilityUiへ委譲。ファイル削除やAppQuestCollection変更を行わない。
実確認ダイアログには対象ID/任務名・この起動中だけ・原本保持・カスタム枠維持を表示する。
全件非表示後も再表示バナーを残し、操作後は既存MainController描画へイベント通知する。
読取用QuestListV1そのものは全観測を引き続き返す。画面投影だけで隠すので既存プラグインのデータを削らない。
受諾中/カスタム/非受諾の順序、既存保存形式、任務達成条件、期限計算、観測時刻は変更しない。

## 検証
修正前の実removeを隔離した合成JSON/キャッシュへ実行し、同じ原本保持試験で失敗を確認。
新コマンド21件とGUI境界2件は独立Sessionを使い、global coreのinit/closeをしない。
実split製品JARの別JVMで、確認・キャンセル・全件非表示・再表示・全件非表示後の復帰入口・
確認中競合と再試行しないこと・元設定/未知フィールド/コメント/受諾状態/キャッシュを保持することを確認する。
さらに別のJVMで非表示状態が持ち越されないことを検査する。
verify_r3の既存全条件に追加し、新GUIのskipだけでは完了できない。
最終全体CIとmergeの実績はPRへ記録する。個別合格を未来の合格に転用しない。

## 残件
定義編集・明示的な永続退避/削除・編集対象の内容ハッシュ照合、同名カスタム定義の変更監視、
任務UI全体の機能JAR化、工廠備考の読取分離、全writer同期、残るP1/P3は未完了。
既存の他画面からの編集・削除経路まで今回一括変更したわけではない。
非表示の変更不能データを、原子的なゲーム状態snapshotと取り違えない。
全148任務の意味照合、未知形式変換、Issues無効の原稿移管、Mint/本人データ/公開も別に保持する。

## 運用
実行は合成データだけの隔離GitHub runner。local container起動は失敗しておりローカル実行済みとしない。
Mint/OS/現用JAR/auto.sh/本人の設定・履歴・プラグイン・バックアップは変更しない。
元環境削除、forcepush、Release/タグ公開、有料AI呼出し、KQS別repo変更を行わない。
