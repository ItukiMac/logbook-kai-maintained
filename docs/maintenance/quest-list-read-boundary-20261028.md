# 任務一覧の読取り専用境界 — 2026-10-28

基点はPR64統合 a273c6a4d2a70e0d5c9e84e0ae11308312c33b6f。
基地の未統合PR65とは別の、任務一覧に限定した変更である。

## 実装
QuestListV1は観測済み任務の表示用値と一覧を不変コピーで返す。
ID整合性、任務名・説明、カテゴリ・種別・状態・進捗・報酬・受諾フラグ・保存済み期限を保持する。
observedAtは実際の受信時刻をそのままコピーする。取得時刻で置換せず、復元データのnullを新しい観測にしない。
旧進捗画面への変換は毎回新しいbean/listを返す。既存QuestPane(AppQuest)コンストラクタも維持する。
QuestPaneは表示と検索・進捗を同じ不変値から開始する。進捗画面のその後の実観測更新・季節版判定は従来処理のまま。

MainController.questは一度だけ取得した一覧を比較と描画に使う。
描画によるカスタム任務キャッシュの削除とConfig.store呼出しを除去した。
ID10001〜10005のキャッシュは観測済み一覧から隠すだけで、原本・保存済み設定は保持する。
実ファイルのカスタム任務は従来どおり受諾中と非受諾の間に表示する。
ハッシュだけの比較を値の等価比較へ変更し、Aa/BB等のハッシュ衝突でも表示変更を見逃さない。
同じ内容なら既存コントロールを再利用し、表示設定変更を反映する。
欠損した表示文字列やカテゴリは表示時だけ安全に扱い、元のnullを書換えない。

## 実検証と範囲
読取契約17件の単体試験は合成入力のみ。グローバルcore初期化や終了で他試験を汚染しない。
実MainController.questとQuestPaneを製品split JARから独立プロセスで起動する。
元の描画処理がキャッシュと設定を書き換えることを同じGUI試験で再現してから修正する。
修正後はキャッシュの保持、設定とカスタムJSONのバイト不変、受諾/カスタム/非受諾の順序、
50/80%表示、展開、ハッシュ衝突、無変更時の再利用、観測時刻、非表示、旧コンストラクタを確認する。
ブラウザ、メインinitialize、プロキシ、明示削除メニューは呼ばない。
全CIの最終head・試験実績・統合結果はPRの証跡を参照する。個別合格を全体合格へ転用しない。

## 未完了として維持するもの
任務UIの物理的な機能JAR化、編集・削除コマンドの安全な公開契約化、工廠備考とカスタムファイルの読取分離は未完了。
今回は新しい機能JAR、配布プロファイル、保存形式を作らない。任務判定条件と期限計算も変更しない。
元からある明示的なremove/removeAll操作は変更しておらず、その安全性の全面認証は今回の範囲外。
既存のカスタム任務監視は存在有無が基準であり、同名ファイルの内容だけの変更検知は後続課題。
非同期の全legacy writerや外部プラグインと完全に原子的なスナップショットとは主張しない。
残るP1/P3、全148任務意味照合、未知形式移行、Issue無効による移管待ち、Mint/本人データ/公開も保持する。

forcepush、Release/タグ公開、有料AI/API実行、KQS別repo変更は行わない。
