# P1 / D4: immutable shared definition contract, version 1

Implemented: GameDataView (read-only snapshot + subscription contract), GameDefinitionSnapshot (defensive copies, independent streams, deterministic fingerprint and managed-resource whitelist), and explicit host-side GameDefinitionService.reload(Path). The loader reads the active pointer once, pins that generation, checks every manifest file for path/symlink/size/hash/strict JSON validity, then publishes one fully-built snapshot atomically. It never writes active.json, installs a pack, accesses the network or includes config/customquest/history/plugins.

Readers must acquire ONE snapshot per logical operation and use it for all resources. Retained references keep the previous generation even after a reload. Missing resources in that snapshot stay missing; no silent bundled fallback. Reload failure preserves the previous snapshot. Identical generations are no-ops; changing the content of an existing generation ID is rejected. Notifications are synchronous, serial, future-only and on the publisher thread. Subscribers must marshal JavaFX work. Listener/error-sink exceptions do not roll back a committed snapshot or suppress later subscribers. Reentrant publication is rejected. Closing one subscription does not remove another registration of the same callback.

Trust boundary: hashes recheck a previously staged local generation; the local manifest is not independent publisher authentication. The service validates JSON structure, not game-rule correctness. Source validation and signed/independently authenticated distribution remain separate.

IMPORTANT integration boundary: this additive API does not silently replace legacy static caches or claim that existing KLB/KQS binaries have migrated to this contract. It is explicitly instantiated by a host/test, not enabled on startup. Remaining D4 work is staging typed consumers/caches and switching all GUI/quest/KQS consumers under this contract. General mutable game-state events and wide plugin extraction also remain P1/P3 work. No release or Mint changes.
